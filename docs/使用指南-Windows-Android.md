# 📱 Windows / Android 使用指南

## 一、先让 App 上线（三选一，推荐方式 ①）

App 是纯静态网页，部署后 **Windows / Android / iOS / Mac 全平台通用**。

### 方式 ① Netlify（最简单，5 分钟，免费）
1. 打开 https://app.netlify.com/drop
2. 把整个 `expiry-butler` 文件夹**直接拖进网页**
3. 几秒后得到网址，如 `https://xxxx.netlify.app` —— 完成！
4. （可选）注册账号后可在 Site settings 改名

### 方式 ② GitHub Pages（免费、长期稳定）
1. 在 GitHub 新建仓库，例如 `expiry-butler`
2. 上传 `expiry-butler` 文件夹里的所有文件
3. 仓库 Settings → Pages → Branch 选 `main` → Save
4. 访问 `https://你的用户名.github.io/expiry-butler/`

### 方式 ③ 局域网（不上网也能用，适合自己电脑+手机）
在电脑的项目文件夹运行：
```bash
python3 -m http.server 8080
```
- 电脑访问：`http://localhost:8080`
- 手机（连同一 Wi-Fi）访问：`http://电脑的局域网IP:8080`
  - Windows 查 IP：命令行输入 `ipconfig`，找「IPv4 地址」如 `192.168.1.5`
  - ⚠️ 此方式无 HTTPS，推播通知功能受限；且电脑关机手机就用不了

## 二、Windows 安装成桌面 App

1. Edge 或 Chrome 打开上线后的网址
2. 点地址栏右侧的 **「⊕ 安装」** 图标（或菜单 → 应用 → 将此站点作为应用安装）
3. 桌面/开始菜单出现「效期管家」图标，点击即以独立窗口打开
4. 首次打开会请求通知权限 → 点 **允许**

## 三、Android 安装成手机 App

1. Chrome 打开网址
2. 菜单（⋮）→ **「添加到主屏幕」/「安装应用」**
3. 主屏幕出现 App 图标，全屏运行，和原生 App 一样
4. 首次进入点右上角 🔔 → 允许通知

## 四、日常怎么用

### ➕ 手动添加
1. 点底部「＋ 手动新增」
2. 选择类型：💳 订阅服务 / 🥬 效期物品
3. 填名称——**输入 Netflix 等常见服务名时，会自动提议官方取消页和价格，点一下就带入**
4. 设定扣款日/有效期、金额、提前提醒天数 → 保存

### 📷 拍照识别
1. 点底部「📷 拍照识别」→ 拍发票或包装上的日期
2. AI 自动识别日期和金额 → 确认候选日期 → 「套用到表单」
3. 补个名字保存即可

### 🔔 提醒机制
- 到期前 N 天（默认 3 天）及逾期时推送系统通知
- 卡片按紧急度变色：绿=正常 / 黄=即将到期 / 红=已过期或即将扣款
- 同一项目同一状态每天只提醒一次，不会骚扰

### 🚫 取消订阅
- 订阅卡片上点「🚫 一键前往取消页 ↗」直达官方管理页面
- 处理完点 ✓ 标记，自动统计今年帮你省了多少钱

### 📴 离线
安装为 PWA 后，断网也能查看和管理所有记录（仅 OCR 识别首次需要联网下载模型）。

数据保存在设备本机（localStorage），不经过任何服务器。
